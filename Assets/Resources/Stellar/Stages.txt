# ============================================================
#  星空リバーシ ステージ定義
# ============================================================
#  ・1面 = 8行 x 8文字。B = 新月(あなた)、W = 満月(相手)、. = 空き。
#  ・上から順に 1面、2面、3面…になります。面の数は決まっていません。
#    ステージ選択の月の数は、ここに書いた面の数で決まります。
#  ・面と面の間に空行を入れても入れなくても構いません(64文字ごとに次の面になります)。
#  ・# から後ろ(と // から後ろ)はコメントです。
#  ・遊ぶ順番は、書いた順番です。前の面をクリアすると次の面が現れます。
#  ・ここに書いた面のあと(29 面の次から(30 面から))は、Pool.txt の面から抽選する「ランダム面」になります。30 面以降の手作りの面も、抽選のもとに加わります。
#  ・5 の倍数の面(5, 10, 15 …)は「LUNATIC」。月が赤くなる、難しい面です。そこに難しい面を置いてください。
#    難しさは、相手がどう打っても勝てる最短の手数と、勝てる手の少なさで決めています。
#
#  ゲームの決まり:
#   - あなたが新月を置くと、挟んだ満月が新月になります(オセロと同じ)。
#   - そのあと相手(満月)も必ず打ちます。相手は、打てる所の中からランダムに選びます。
#     そのため、相手がどこに打っても必ず解ける面だけを入れてください。
#   - あなたに打てる所が無いときは、相手がもう一度打ちます。
#   - 全てのマスが新月になればクリアです。
#
#  解けるかどうかは、再生中に右上の歯車 → 「ステージを検証」で確かめられます
#  (結果は Console に出ます)。
#
#  書き方の例(使うときは行頭の # を取ってください):
#
#  BBBBBBBB
#  BBBBBBBB
#  BBBBBBBB
#  BBBWBBBB
#  BBB.WBBB
#  BBBBBBBB
#  BBBBBBBB
#  BBBBBBBB
# ============================================================
